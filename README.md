# CSI Shanthi Church Website

This version is optimized for GitHub Pages and does **not** embed large images inside `index.html`.

## Repository structure

```text
/
├── index.html
└── assets/
    ├── church-exterior.png
    ├── altar-enhanced.png
    └── offerings-qr.png
```

## Upload to GitHub Pages

Upload `index.html` and the entire `assets` folder to the root of your GitHub Pages repository.

Do not rename the files unless you also update the paths inside `index.html`.

## Notes

- The church exterior and altar images are loaded from the local `assets` folder.
- The offerings QR is loaded from the local `assets` folder.
- The latest YouTube service thumbnail is loaded directly from YouTube's image CDN.
- The website remains responsive/mobile-friendly.
